WORKSPACE 03

Learn GIS

A concise workflow with practical guidance and a knowledge check.

01 Prepare the source map

Use a clear scan with the full map frame, grid ticks, labels and neatline visible. A tilted phone photograph can introduce perspective distortion.

02 Choose the coordinate reference system

Identify the original map CRS if known. Select a suitable target CRS for the study area and intended measurements. Confirm datum, projection and units.

03 Add well-distributed GCPs

Use stable, identifiable features or grid intersections. Distribute points around the image, including corners and the centre. Avoid clustering all points in one area.

04 Select a transformation

Affine (often called polynomial order 1) can model translation, rotation, scale and shear. Higher-order polynomials and thin plate spline can model more distortion but can also warp areas between points.

05 Validate independently

Inspect residuals, overlay the output with trusted reference data, and check known features throughout the map. Low training-point RMSE alone does not prove accuracy everywhere.
